```
settings  : greedy, role-marker + repetition stops on, max 300 new tokens; only the threshold changes
traces    : 72 reference traces checked (P(EOS) present at every step)
used      : 4-bit: 4-bit engine 76; BF16: BF16 engine 6; BF16: Hugging Face reference 71;

```

## Decision rule (fixed before the results)

- Every reply is generated with the chat defaults except the threshold: greedy, the role-marker and repetition stops on, max 300 new tokens; only --eos-min-p changes between rows.
- Human labels (one per distinct reply text): A complete and coherent single reply; B understandable but unnecessarily verbose; C invented conversation turns; D prematurely truncated legitimate answer; E incorrect or incoherent answer.
- C1: at least 75% of the greeting cases (at least 8) give a single coherent reply (label A or B) with the default system prompt.
- C2: no factual, explanation, code, list or multi-turn reply, with either system prompt, is labelled D where the threshold changed it.
- C3: no reply the threshold changed gets worse than with the threshold off: labelled D or E where the threshold-off reply was not, or its code stops compiling.
- C4: C1-C3 hold for both the BF16 engine and the 4-bit engine.
- A threshold qualifies only if C1-C4 all hold; of the qualifying thresholds the largest (most conservative) is recommended. If none qualifies, --eos-min-p stays opt-in and the default stays 0 (off).
- Replies a threshold does not change need no new label: they are the threshold-off reply.

Rubric: **A** complete and coherent single reply, **B** understandable but unnecessarily verbose, **C** invented conversation turns, **D** prematurely truncated legitimate answer, **E** incorrect or incoherent answer.
